# Анимации LottieFiles

Все анимации взяты из бесплатной библиотеки [LottieFiles](https://lottiefiles.com) и распространяются по
[Lottie Simple License](https://lottiefiles.com/page/license): коммерческое использование и изменение разрешены,
указание автора не обязательно. Изменения для сайта: цвета приведены к палитре Bilim Merkezi, холст обрезан
по рисунку. Производные файлы распространяются на тех же условиях.
